Project Overview

Smart Investment Advisor is a full-stack web application built with Python Flask on the backend and modern HTML/CSS/JavaScript on the frontend. It leverages SQLite for data persistence, Werkzeug for authentication, and Chart.js for interactive visualizations.

The recommendation engine analyzes user inputs — age, monthly income, risk tolerance, and financial goals — to generate a customized investment plan complete with portfolio allocation percentages, expected return ranges, and personalized insights.

The SIP Calculator uses the standard future value formula: FV = P × [((1+r)^n − 1) / r] × (1+r), where P is monthly investment, r is monthly rate, and n is number of months.
